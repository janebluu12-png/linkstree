# ☁ ร้านขนมลิงก์ในฝัน (Sweet Links)

หน้ารวมลิงก์ที่ไม่มีปุ่มธรรมดาเลย — ทุกลิงก์คือ **ขนมหน้าสัตว์ในตู้กระจก** ตั้งอยู่ในคาเฟ่เล็กๆ (หน้าต่างโค้งมีม่าน ธงราว กระดานเมนู ชั้นวางขวดโหล ต้นไม้ โต๊ะกาแฟ) วาดด้วยเส้นดินสอสั่นๆ ฟีลฟุ้งๆ เหมือนฝัน

- 🧁 **จิ้มขนม** = เปิดลิงก์ (ขนมจะเด้งดึ๋ง ยิ้มตาหยี มีดาวกระจาย)
- 🔔 **กดกริ่ง** บนเคาน์เตอร์ = ได้ "ขนมเสี่ยงทาย" พร้อมคำอวยพร
- 💡 **ดึงโคมไฟ** มุมขวาบน = สลับเป็นร้านตอนกลางคืน (ฟุ้ง ม่วง มีดาว นอกหน้าต่างมีพระจันทร์)
- 📜 **เมนูวันนี้** ด้านล่าง = รายชื่อลิงก์แบบตัวหนังสือ เผื่ออยากกดเร็วๆ

## แก้ลิงก์ของตัวเอง

เปิด `app.js` แล้วแก้ `CONFIG` ด้านบนสุดที่เดียว:

```js
{ title: "Instagram", note: "รูปน่ารักอยู่นี่!", price: "฿0 · ฟอลเลย",
  url: "https://instagram.com/yourname", treat: "cupcake" }
```

`treat` เลือกได้: `cupcake` (คัพเค้กชิบะ), `toast` (ขนมปังหมาไข่ดาว), `melonpan` (เมล่อนปังแมว),
`bun` (ซาลาเปาหมี), `daifuku` (ไดฟุกุกระต่าย), `shortcake` (ช็อตเค้ก), `croissant` (ครัวซองต์), `pudding` (พุดดิ้ง)

ใส่รูปโปรไฟล์ได้ที่ `avatar`, เปลี่ยนคำทำนายที่ `fortunes`

## เปิดดู / ขึ้นเว็บ

ไม่ต้อง build อะไรเลย — เปิด `index.html` ได้ทันที
ขึ้นเว็บฟรีด้วย GitHub Pages: Settings → Pages → เลือก branch แล้วกด Save

ข้อความบนกระดานเมนูในฉากหลัง แก้ได้ใน `index.html` (ส่วน `<!-- กระดานเมนู -->`)
