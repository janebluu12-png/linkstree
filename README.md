# ☁ ร้านขนมลิงก์ในฝัน (Sweet Links)

หน้ารวมลิงก์ที่ไม่มีปุ่มธรรมดาเลย ทุกลิงก์คือ **ขนมหน้าสัตว์ในตู้กระจกหน้าร้าน** วาดด้วยเส้นดินสอสไตล์การ์ตูน
ตั้งอยู่ในคาเฟ่เล็กๆ (หน้าต่างโค้ง แมวนอนบนขอบหน้าต่าง ธงราว กระดานเมนู) มี **หลังร้าน** ไว้แก้ทุกอย่างเองได้

## รูปแบบตู้ (เลือกได้ที่หลังร้าน)

| แบบ | หน้าตา | เหมาะกับ |
| --- | --- | --- |
| **มีหมวดหมู่** | ขนมหน้าตาเดียวกันวางเป็นกลุ่มบนชั้น (1 กลุ่ม = 1 หมวด) จิ้มแล้ว **ซูมเข้าไป** เป็นชั้นวางระยะใกล้ มีถาดและป้ายราคาของแต่ละลิงก์ | ลิงก์เยอะๆ |
| **ไม่มีหมวดหมู่** | ขนมแต่ละชิ้นคือหนึ่งลิงก์ จิ้มแล้วไปเลย | ลิงก์น้อยๆ (3–9 อัน) |

ลูกเล่นอื่นๆ: 🔔 กดกริ่งบนเคาน์เตอร์ = ขนมเสี่ยงทาย · 💡 ดึงโคมไฟมุมขวาบน = ร้านตอนกลางคืน · ☕ เมนูบนโต๊ะคาเฟ่ = รายชื่อลิงก์แบบตัวหนังสือ
ลิงก์หมวดแชร์ได้ด้วย เช่น `https://เว็บของคุณ/#/social` จะเปิดมาที่ชั้นของหมวดนั้นเลย

## โครงสร้างไฟล์

```
public/            ← หน้าเว็บ (Cloudflare จะ deploy โฟลเดอร์นี้)
  index.html       หน้าร้าน
  admin.html       หลังร้าน (/admin)
  config.json      ข้อมูลตั้งต้น (ใช้จนกว่าจะบันทึกจากหลังร้านครั้งแรก)
  treats.js        ภาพวาดขนมทั้งหมด (SVG)
functions/api/     ← ระบบหลังบ้าน (Cloudflare Pages Functions)
  config.js        GET อ่านข้อมูลร้าน / PUT บันทึก (ต้องมีรหัสผ่าน)
  auth.js          เช็กรหัสผ่าน
lib/               ตรวจข้อมูล + เช็กรหัสผ่าน (ใช้ร่วมกันใน functions)
```

## 🚀 Deploy บน Cloudflare Pages (ผ่านหน้าเว็บ ไม่ต้องใช้คำสั่ง)

1. **สร้างที่เก็บข้อมูล (KV)**
   Cloudflare Dashboard → **Storage & Databases → KV** → **Create** → ตั้งชื่ออะไรก็ได้ เช่น `sweet-links`
2. **สร้างโปรเจกต์ Pages**
   **Workers & Pages → Create → Pages → Connect to Git** → เลือก repo `linkstree` และ branch ที่ต้องการ
   - Framework preset: **None**
   - Build command: *(เว้นว่าง)*
   - Build output directory: **`public`**
   → กด **Save and Deploy**
3. **ผูก KV กับโปรเจกต์**
   เข้าโปรเจกต์ → **Settings → Bindings → Add → KV namespace**
   - Variable name: **`LINKS_KV`** (ต้องตรงตัวนี้)
   - KV namespace: เลือกอันที่สร้างในข้อ 1
4. **ตั้งรหัสผ่านหลังร้าน**
   **Settings → Variables and Secrets → Add** → Type **Secret**
   - Name: **`ADMIN_PASSWORD`** · Value: รหัสผ่านที่ต้องการ (ยาวๆ เดายากๆ)
5. **Deploy ใหม่อีกรอบ** (Deployments → ⋯ → Retry deployment) เพื่อให้ค่าในข้อ 3–4 มีผล
6. เข้า `https://ชื่อโปรเจกต์.pages.dev/admin` → ใส่รหัสผ่าน → แต่งร้านแล้วกด **บันทึก** หน้าร้านจะอัปเดตทันที

> ทำครบข้อ 3 และ 4 ให้ได้ทั้งสองข้อ — ถ้าขาด KV หรือรหัสผ่าน หลังร้านจะบอกว่าขาดอะไร

### หรือ deploy ด้วยคำสั่ง

```bash
npm install
npx wrangler login
npx wrangler pages deploy public      # รันที่โฟลเดอร์หลักของ repo (functions/ จะถูกส่งไปด้วย)
```
แล้วทำข้อ 3–5 ด้านบนในหน้า Dashboard

## ลองบนเครื่องตัวเอง

```bash
npm install
echo "ADMIN_PASSWORD=รหัสที่อยากใช้" > .dev.vars
npm run dev                           # เปิด http://localhost:8788 และ /admin
```

## ความปลอดภัย

- บันทึกข้อมูลได้เฉพาะคนที่มีรหัสผ่าน (เทียบแบบเวลาคงที่ และช้าลงเมื่อใส่รหัสผิด)
- ลิงก์รับเฉพาะ `https://`, `http://`, `mailto:`, `tel:` (กันลิงก์อันตรายแบบ `javascript:`)
- ข้อความทุกช่องถูกตรวจความยาวและ escape ก่อนแสดงผล
- อยากล็อกหลังร้านเพิ่มอีกชั้น ใช้ **Cloudflare Access** ครอบ path `/admin*` และ `/api/auth` ได้ (ฟรีสำหรับไม่กี่คน)
